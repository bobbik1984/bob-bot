# BobBot 原型能力更新（2026-11-09 → 2026-11-10）

> 本文记录测试原型（`prototype/`，Node.js + DSH）这一轮从“能跑”到“日常可用、有主动性、能受控自扩展”的全部更新。
> 部署实例：**https://ry.bobbik.org**（腾讯云 RY，Ubuntu 24.04，2C/2G + 2G swap，Node 24.22.2）

## 0. 一句话总结

BobBot 现在是一个**能长期住在 VPS 里、主动关心你、记得你、能给自己装小功能，并且一条命令就能发布更新**的个人助理原型。

## 1. 主要功能优势（请记住）

1. **一条命令发布**：在 x1t 上 `git push` 后执行 `bash scripts/deploy-ry.sh`，自动完成 RY 拉取、按需安装依赖、重启服务、本机与公网双重健康检查；站点设置页显示构建号与部署时间（`/api/version`）。
2. **官方微信通道，不是第三方协议**：使用腾讯官方 iLink（OpenClaw 核心）与自建 bridge；扫码登录、私聊对话、微信提醒都走官方接口，避免 wechaty 类方案的封号风险。
3. **三层提醒覆盖**：应用内收件箱（权威）+ 手机主屏幕推送（iOS APNs / PWA）+ 微信（最近活跃会话内尽力送达）；失败如实记录，不伪装成功。
4. **卡片化表达**：图标块 + 标签 + 左标签右值的对齐信息行 + 底部双按钮；只展示对用户有效的字段，不出现时区名、内部 ID、技术命令。
5. **文员与通信分离**：文员页只放「待办 / 定时任务 / 收件箱」；消息渠道、微信登录、时区全部收进设置页，和微信通信同级。
6. **主动性可调 0–1**：高冷 / 得体 / 积极 / 粘人四档，滑块连续调节；档位改变频率、最小间隔和语气，但安静时段、每日上限、忙碌跳过等硬规则不放松。
7. **记忆 + 做梦**：夜间把最近 24 小时对话、待办、定时任务整合成长期记忆（事实/偏好/模式/待跟进）与观察；主动关心会使用这些记忆。
8. **受控自扩展（creator mode）**：Bob 可以安装「功能包」给站点加工具、HTTP 路由和设置面板；只能写入 `data/features/`，安装前展示完整代码，加载失败自动跳过，不碰主代码。
9. **手机端体验**：PWA 可添加到主屏幕；支持语音输入、会话重命名、打开时回到上次页面、超过 3 小时未续聊自动新会话、中英双语。
10. **安全与隔离**：危险动作审批、MCP 命令存在性检查、扩展启动失败自动降级、功能包安装审批、微信推送限制如实呈现。

## 3. 对话体验

- **卡片重做**（`3c43ea3`）：头部图标 + 彩色胶囊标签 + 时间；标题 17px；信息行两端对齐（时间/备注/重复/下次/发送到）；引用块只放原文；底部等宽双按钮（主操作蓝色、次操作浅灰/浅红）；保存态只保留绿色标签，不再整卡描绿。
- **Orb 形象与动效**（`8ecc5b5`，2026-11-10 改版）：主体是**纯色圆环**（无渐变、无高光、无阴影），休息时环变淡、气泡从环边飘出；思考时环上有一段旋转的弧与头顶思考云；回答时环轻微脉动、小圆点从“嘴”部飞出。应用图标（PWA/主屏幕）同步改为同款圆环。聊天页不再显示“休息中/思考中”文字。
- **多语言**（`8ecc5b5`）：设置 → 通用 → 语言，跟随系统 / 简体中文 / English；日期、时间、周几、月份随语言变化。
- **浏览器只对 agent 开放**（2026-11-10）：移除右上角浏览器入口；只有 agent 调用 `browser_request_human` 请求登录/验证时才自动弹出虚拟窗口，顶部提示“处理好后交还”，处理完自动关闭。真正的网页操作始终由 Bob 在后台完成。
- **对话重命名**（`b16231b`）：桌面悬停出现铅笔/垃圾桶；手机长按或双击重命名，左滑删除保留；行内输入框，回车保存、Esc 取消。
- **启动恢复**（`b16231b`）：记住上次对话与页面（对话/文员），下次打开回到原处，不再跳到最新回复。
- **3 小时新会话**（`b16231b`）：上次对话最后更新超过 3 小时则进入新会话，旧对话保留在历史。
- **语音输入**（`b16231b`）：输入框麦克风按钮，浏览器语音识别实时填入，录音时红色脉冲；不支持的浏览器自动隐藏。

## 4. 文员（Clerk）

- 页面只保留三块：**待办 · N**、**定时任务 · N**、**收件箱**；无数据时显示 0 与一句可直接照做的示例，不再是空白页（`3d2634f`）。
- 待办支持勾选完成/撤销、删除；定时任务支持立即运行/发送、暂停/恢复、移除、查看运行。
- **消息渠道与添加渠道、时区**移到设置页（`a52e162`），渠道卡片改为两行式（名称 + 类型/掩码/签名状态 + 发测试消息）。
- 微信登录成功后自动创建名为「微信」的提醒渠道（只创建一次，删除后不会反复重建）。

## 5. 微信（官方 iLink）

- 引入并改造官方 OpenClaw 微信核心与 bridge（`51d11e4`），修复了原 bridge 只弹二维码、不保存 token/账号的问题；登录态写入 `~/.wechat-bot/`，账号 id 写入 `data/wechat/account.txt`。
- 扫码入口在「设置 → 连接 → 消息渠道 → 添加渠道 → 微信（官方 iLink）」：生成/刷新二维码、轮询状态、登录后自动切换文案（`92c7769`）。
- 官方 bridge 暴露 `GET /status`、`POST /send`；BobBot 新增 **bob-agent 兼容 API**（`61e9a07`）：`POST /v1/chat`（SSE：`text`/`thinking`/`tool_start`/`tool_end`/`done`）、`GET /v1/conversations`（返回数组）、`GET /v1/health`。每个 `from_user` 对应一个 `WeChat · 昵称` 会话。
- 主动发送使用每个联系人最近一条来信的 `context_token`（`28b9d8c`），返回 `usedContext` 与 token 年龄；token 缺失/过期时微信可能静默丢弃，应用内收件箱始终保留结果。
- 限制（已知）：只处理私聊文字；图片/语音/文件回提示；群聊未接入；个人微信官方接口本身有会话上下文限制。

## 6. 提醒与推送

- **iOS 推送修复（2026-11-10）**：VAPID 的 `subject` 原为 `mailto:bob@localhost`，Apple 返回 `403 BadJwtToken`，表现为通知永远收不到；改为 `https://ry.bobbik.org`（可用 `BOB_PUSH_SUBJECT` 覆盖），实测 APNs 返回 201。另修复设置页缓存订阅数导致启用后仍显示“尚未开启”，以及 iOS 权限询问必须在点击手势内直接调用。

- **iOS**：PWA + APNs Web Push。`manifest.webmanifest` + `sw.js` + VAPID；设置 → 连接 → 手机通知启用后自动创建「手机通知」渠道；发送失败清理失效订阅（`3b70271`）。
- **Android**：开发文档确定使用**独立 APK 客户端**（不走 FCM），见 [ARCHITECTURE.md](ARCHITECTURE.md) §5。
- **渠道**：Lark / 企业微信 / Telegram / Discord / 微信（官方）/ 手机通知；每条投递结果写入收件箱 `delivery`。
- 后续：邮件、Server酱/Bark 等兜底渠道。

## 7. 记忆、做梦与主动关心

- **记忆**（`e65415b`）：`data/memory.json`，四类 `fact / preference / pattern / open_loop`；Bob 可用 `memory_add` / `memory_forget` 维护，设置页可查看和逐条删除。
- **做梦**：每天 03:30（本地时区）读取最近 24 小时对话、待办、定时任务，要求模型返回 JSON（新增/更新/删除/观察），去重后写回；失败不写入。设置页可「现在整理想一次」。
- **主动关心**：在设定时间（默认 09:00 / 18:30）把待办、任务、最近活动、记忆与观察交给模型；只有确实值得才说话，否则回复 `[SILENT]`。消息进入「提醒」对话，并尽力发手机推送（2026-11-14 起不再写入文员收件箱，见 §11.8）。
- **主动性 0–1**：高冷（1 次/天，8h 间隔）/ 得体（2 次/天，4h）/ 积极（3 次/天，3h）/ 粘人（4 次/天，90m）；语气随档位变化。22:00–08:00 安静、每日上限、最小间隔、忙碌跳过为硬规则。
- 设计参考：Grok Bot Routines（工作日/安静时段/可行动才提醒/一次性观察自动过期）、Raven Proactivity（周期性 Planner + NudgePolicy）、Muse（记忆作用域与 observer/reconciler）。

## 8. 功能包（受控自扩展）

- 位置：`data/features/<name>/{feature.json, server.mjs, panel.html?}`。
- `export default function setup(ctx)` 可用 `ctx.registerTool()`、`ctx.registerRoute()`（`/api/f/<name>/…`）、`ctx.storage`、`ctx.log`。
- 安装前必须审批并展示代码；单文件 ≤ 60 KB，setup 超 5 秒算失败；加载失败标记 error 并跳过，不影响主服务；工具下一轮对话生效（重启 DSH，不重启站点）。
- 设置 → 助理 → 功能扩展：打开面板（iframe）、移除。
- 限制：与主进程同权限运行，只接受用户亲自确认过的代码；正式版应改为子进程隔离。

## 9. 安全与失败隔离

- 危险动作（命令、写文件、安装、MCP、删除/暂停日程、功能包）一律审批；审批卡展示命令/代码/影响。
- MCP 命令不存在时直接拒绝，不再弹无效确认；MCP/技能数量有上限。
- 扩展导致 DSH 启动失败时，自动降级为“无扩展启动”并提示用户（`ensureAgent` 兜底）。
- 微信主动推送失败、PWA 推送失败都会记录在投递结果中，不伪造成功。
- 待办：功能包子进程隔离、命令分级审批、Bob 自身代码目录只读。

## 11.1 浏览器能力与可靠性升级（2026-11-10）

- **看得更全**：快照覆盖 iframe（含跨站）、开放 Shadow DOM 与靠 `cursor:pointer` 识别的 `div` 按钮，并显示勾选、展开、已填内容和下拉选项，提示屏幕外还有多少元素。
- **做得更多**：下拉选择、悬停、按键、后退、等待文字出现、全文/表格/链接分段读取、多标签页、下载（50 MB 上限）、上传（必须审批）。
- **更安全**：密码与验证码字段的值不进模型，Bob 也不能往里输入；地址检查覆盖重定向、框架和点击的链接；元素被遮挡时拒绝点击，审批判断的就是实际点击的元素；对话框不再卡死页面，确认框默认取消。
- **更可靠**：页面按网络请求静默判断加载完成；Chromium 崩溃后下一次操作自动重启；状态文件原子写入。
- **定时任务如实**：最近 20 次运行记录（状态、耗时、费用、投递）；没有结果算失败；登录过期标记“需要你”，点「去处理」登录后自动重跑；审批和接管发手机推送。
- 限制：定时任务仍不能等待审批，只能跳过并报告；关闭式 Shadow DOM 不可见；真实办公站点尚未验证。

## 11.2 Routine、待批草稿与记忆修复（2026-11-10）

- **对话存为 Routine**：从真实步骤生成剧本，确认后试运行，人工启用才定时；运行结果按校验如实记录。
- **待批草稿**：定时任务准备好动作，用户在文员页批准后才执行，执行不再经过模型。
- **修复做梦与主动关心**：原来只等 400 毫秒就收答案，真实模型来不及回复，导致线上做梦全部失败、主动关心永远沉默。现在等到回合结束。
- **修复记忆不生效**：原来只有主动关心读取记忆，普通对话、微信和定时任务都读不到。现在全部注入，且排序不再只看最新 10 条。
- **主动性档位真正生效**：高档位增加检查时间点；沉默不占额度；错过整分钟不再丢失。达到花费上限时做梦和主动关心不再调用模型。
- 限制：成功校验是模型自评；重放依赖元素名称，页面改版会失败；真实模型下的做梦质量待观察。

- 验证：真实浏览器驱动 9 项交互检查通过（脚本未入库）；中英文、浅色/深色、手机/电脑截图人工核对。真机 iOS/Android 未验证。

## 11.4 Bob 可以改自己：沙箱功能包与试用回退（2026-11-10）

## 11.5 人工接管窗口重做（2026-11-10）

- **打字**：点页面上的输入框后，底部输入框即代表该框，边打边同步到页面；支持手机键盘、中文输入法、粘贴、短信验证码；密码框自动隐藏，数字/验证码框弹数字键盘；回车即回车。

## 11.6 聊天任务完成通知与推送诊断（2026-11-10）

- **原因**：此前只有定时任务经「手机通知」渠道推送，聊天里的任务做完没有任何推送。
- **新增**：聊天回合结束且你没在看 Bob 时推送他最后说的话；默认只在耗时 ≥20 秒或步骤 ≥3 时发，可选“每次回复”或“不通知”。“没在看”以页面可见且有焦点为准，各设备每 15 秒上报，挂在另一块屏幕上的标签页不会挡住手机。
- **不重复**：微信会话、定时任务、主动关心、做梦各自已有出口，不再重复通知。中断与额度用完会通知原因。
- **诊断**：失败时记录推送服务返回的状态码与原因，临时错误重试一次，设置页显示最近一次结果，`/api/push/log` 保留最近 20 次。
- **点开通知的去处**：对话完成、审批、接管请求打开对应对话；定时任务结果、待批草稿、需要你处理打开文员页。应用已打开时直接切换、不重载；没有目标时仍回到上次停留的页面。（此前一律打开 `/`，所以会回到上次停留的文员页。）
- **已知限制**：电脑上页面可见且有焦点时不会推送到手机；iOS 的专注模式/通知摘要仍可能把通知延后或隐藏。

## 11.7 小部件：记住上次内容、深色不再露白（2026-11-10）

- **记住上次内容**：新增 `bob.save(value)` / `bob.state`。页面把小部件存的小段 JSON（≤8 KB）保存在本机，下次一加载就交给它，所以可以先画上次的内容、再后台刷新，不再显示“-”占位。原天气小部件每次打开都强制重新取（要等好几秒），且它在沙箱里用不了 `localStorage`，所以每次都从空白开始。
- **深色白块**：浮层在“已就绪”前整个隐藏；小部件文档从第一帧起强制跟随 Bob 的外观（`color-scheme` 不再由小部件自己声明、也不再跟随手机系统设置）；应用配色以正确的浅/深色值预置。`bob-ready` 只触发一次，主题变化触发 `bob-theme`。
- **天气小部件**：已改为先显示上次读数；只有换了时段（07:00/19:00）或手动点击才强制刷新，平时用服务器缓存。
- **诚实说明**：白块在本机 Chromium 里没有复现（改前改后都是透明的），修的是规范里记载的原因加一道隐藏保险，在 iPhone Safari 上是否彻底解决需要你确认。
