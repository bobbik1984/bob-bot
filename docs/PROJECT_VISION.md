# BobBot — Project Vision（项目愿景）

> **状态**：2026-11-08 立项定稿。本文定义 `bob-bot` 为什么存在、面向谁、解决什么核心痛点，以及它与极客向 `bob-online` (`bob-agent`) 的本质区别。

---

## 1. 一句话定位

**BobBot 是运行在你个人 VPS 上的 7×24 小时消费者级云端 AI 助理：在任何手机或电脑浏览器打开 `bobbot.mydomain.com`，填入自己的模型 API Key 即可对话；内置持久化云端浏览器，遇到登录或验证码时直接在手机网页弹出虚拟窗口点按接力；手把手教它做过一次的事，一键保存为每天自动运行的日常任务（Routines）。**

> **Your 24/7 Cloud AI Companion. Bring Your Own Key. See What It Sees, Tap When It Needs You.**

---

## 2. 为谁而做（Target Audience）

- **核心用户**：**普通办公室白领**。BobBot 是轻量助理，帮他们处理查资料、看后台、汇总信息这类日常办公事务。用户自己填入 DeepSeek / Gemini / OpenAI / OpenRouter 的 API Key，**不需要懂命令行、Coding Harness 或 MCP**。
- **当前阶段**：先由项目所有者在所在地区的 VPS 上自测。租 VPS、配域名与 HTTPS 目前仍需技术操作，普通白领的安装体验在 BB4 及之后解决；「三分钟开箱」只从打开已部署好的实例开始计算。
- **典型使用场景**：
  1. **跨网站日常事务自动化**：每天定时登录没有公开 API 的网页后台（如电商后台、小红书/X 创作者中心、行业数据网、航司查票、内部 OA），抓取最新信息并汇总推送到手机。
  2. **人机无缝接力（Human-in-the-Loop）**：Bob 在云端跑任务时撞上滑块验证码或手机短信验证，用户的手机网页气泡里直接弹出一个实时云端浏览器小窗，手指点两下完成登录，登录态保存在 VPS 上，Bob 接着往下跑。扫码登录需要用第二台设备打开虚拟窗口，因为手机无法扫描自己的屏幕。
  3. **长程异步办事与记忆沉淀**：手机上随口交代一句“帮我对比这三家酒店周六的价格和退改政策”，锁屏干别的事，3 分钟后打开网页直接看带截图证据的对比卡片；个人偏好（常用邮箱、座位偏好、关注列表）自动沉淀。

## 3. 为什么从 `bob-online` 独立孵化 `bob-bot`？（定位切割）

现有的 `bob-online` (`bob-agent v1.0.1`) 是为拥有多台开发机与 VPS 的开发者设计的**“跨设备 CLI 舰队总控台”**；而 `bob-bot` 是做减法并强力补齐“云端 GUI 浏览器接力”的**纯消费者单品**：

| 维度 | `bob-online` (`bob-agent`) | **`bob-bot`（本项目）** |
| :--- | :--- | :--- |
| **目标人群** | 程序员、重度极客（多机、多 Coding CLI） | **纯消费者、泛白领（单台 VPS、零命令行心智）** |
| **初始配置门槛** | 配对多台节点、配置 Claude/Codex/AGY/DSH 路径 | **打开网页 → 设密码 → 填 1 个 API Key → 立即开聊** |
| **执行引擎（Harness）** | 外部重型 CLI 子进程（Claude Code / DSH / Codex） | **Rust 内置轻量 Router-Worker + 内置 Headless Chromium** |
| **遇到网页登录/验证码** | 无头 CLI 直接报错卡死，或需自己用 VNC/SSH 排障 | **网页聊天流内直接弹出可触控的“虚拟浏览器窗口”接力** |
| **导航与心智模型** | 多节点目录、规范项目归一、代码工作树写锁 | **极简三栏：主对话（含虚拟小窗）+ 日常任务（Routines）+ 记忆与网站登录态** |

---

## 4. 核心体验支柱（Core Pillars）

1. **三分钟 BYOK 开箱即用（Zero-Friction Onboarding）**
   浏览器首次打开 `bobbot.mydomain.com`，通过三步向导完成管理员密码设置与模型 API Key 填入（支持 DeepSeek、Gemini、OpenAI、Anthropic、OpenRouter 一键测通），自动配置快慢双模型（Clerk 负责秒回路由，Maker 负责复杂执行），无需写一行配置文件。
2. **手机网页里的“虚拟浏览器窗口”（In-Web Virtual Browser Takeover）**
   VPS 无需物理显卡或重型桌面环境。普段由 Bob 在后台高速无感操作网页；一旦遇到未登录、滑块验证码、扫码或付款确认，前端聊天流内直接展开一个自适应手机屏幕的虚拟浏览器画布（基于 CDP Screencast + WebSocket 双向触控映射），用户在手机浏览器里直接点选、滑动、唤起手机输入法打字，一键交还控制权。
3. **一次登录，持久在线（Persistent Cloud Identity）**
   用户在虚拟窗口里登录过的网站（如 X、淘宝、知乎、Notion、企业后台），其 Cookie 与 LocalStorage 持久保存在 VPS 本地磁盘（站点可能随时让登录失效，能进入服务器的人也能读取这些数据）。Bob 后续执行定时任务时自动复用登录态，并在「网站授权中心」诚实展示各站点登录状态是否有效。
4. **示教即日常（Walkthrough to Routine）**
   用户不用写复杂的定时提示词或脚本。带着 Bob 走通一次任务（含手动辅助登录、指点点击位置），完成后点击「存为日常任务（Routine）」，系统自动将本次操作轨迹提炼为结构化执行剧本并绑定定时触发器（如每天早 8 点）。
5. **无感记忆与防膨胀（Self-Distilling Memory）**
   延续三层记忆精髓，但对消费者隐藏复杂的知识图谱概念。后台自动在闲置时将零散对话蒸馏为清晰可读的「记忆胶囊」（偏好、常用信息、历史决定），用户可随时像管理便签一样查看或划掉某条记忆，运行数月也不会上下文爆炸或变慢。

## 5. 产品原则（Design Principles）

- **Browser as the Fallback API**：办公室用户常用的很多后台没有开放 API，所以必须能操作带登录态的网页；已有官方 API、RSS 或可用连接器时优先使用，因为更稳定，也更少触碰站点的自动化限制。
- **Human-in-the-Loop over Fragile Crack**：绝不试图用黑客手段硬破验证码或风控；遇到阻碍立刻诚实弹窗，让人类用 5 秒钟在手机虚拟窗口里点一下，换取更高的成功率与账号安全；若站点仍拒绝登录，如实告知用户，不绕过风控。
- **DOM First, Vision on Demand**：网页自动操作优先读取精简无障碍 DOM 树（Accessibility Tree + 元素编号标记），只在视觉强依赖或人工接管时开启画面帧，把单任务 Token 成本压到几分钱。
- **Honest Gates**：只读浏览自动放行；发帖、发消息、下单、删除、修改账号设置等不可逆操作，必须弹出带现场截图的审批卡（Allow Once / Reject）。

---

## 6. 明确不做（Non-Goals）

- **不做多机集群调度器**：`bob-bot` 只管好它所在的这一台 VPS，不管理用户的家庭局域网电脑或外部 SSH 节点。
- **不做云端 IDE 或代码编辑器**：不暴露终端（Terminal）、Git 分支树或代码 Diff 视图。测试原型例外：所有者可以让 Bob 在自己的服务器上读写文件、运行命令，每次都需要审批卡确认（见 `prototype/README.md`）；这只用于自用测试，开放给他人前必须重新评估。
- **不绑定黑盒高价模型**：坚持 BYOK（自带 Key），让用户享受 DeepSeek / Gemini Flash 极致的性价比，同时允许为关键任务切换顶级模型。
- **不跑重型完整 Linux GUI 桌面**：不在 VPS 里跑消耗数 GB 内存的 GNOME/KDE + WebRTC 视频编码流，坚持使用超轻量 Headless Chromium + CDP 按需画布推流。目标规格为 2C/4G，2C/2G 须经 BB4 实测后才能承诺。

---

## 7. 与 Grok Bot 的差异（2026-11 第三方评测，待官方资料核实）

- **基本持平，不作为卖点**：定时 Routines、持久登录、人工接管、执行前审批。
- **BobBot 的差异**：数据在自己的 VPS 上、可选任意模型、记忆可查看和删除、适配用户所在地区的办公站点与沟通工具。
- **价格不作为主要卖点**：评测显示 Grok Bot 起步约 $30/月；BobBot 的成本是 VPS 加不超过月度上限的模型费用。

---

## 8. 测试期风险归属与花费

- **风险归属**：测试期由项目所有者自行承担网页内容误导 Agent（提示词注入）的风险，建议使用测试账号，不接入资金类账户。开放给他人使用前必须重新评估，因为普通白领无法自行判断这类风险。
- **花费**：模型 API 默认每月上限 $10，VPS 费用另计，用户可在设置中调整。
- **渠道**：Lark、Telegram、微信 Bot、Discord 与现有 MCP 工具都是可选扩展，不影响核心网页体验。
