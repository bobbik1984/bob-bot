# iPhone 微信收件

RY 的微信收件箱位于「文员」。在 iPhone 用 Safari 打开 [连接 RY](https://ry.bobbik.org/wechat)，使用 RY 自己的 PIN 解锁。

## RY 一次安装

用 iPhone 的 Safari 打开 RY 的「文员 → 微信收件箱」。解锁后点「复制连接码并添加快捷指令」，打开下载的文件，在苹果「快捷指令」提示时粘贴连接码并添加。若 Safari 把文件放入下载列表，点该文件即可。连接码只可投递到收件箱；更换收件密钥会使旧码失效。

从微信或系统截图预览的分享菜单运行该指令。微信仅提供复制时，复制消息后运行它。截图先在 iPhone 上识别成文字，发送到 RY 的是识别结果。RY 先返回收件回执，再从原话提取明确的待办。有截止时间且尚未到期的事项同时生成文员提醒。无法判定或解析失败时显示「待核对」。再次投递相同文字会返回已有回执。

签名模板的源文件是 `shortcuts/RY.cherri`，发布文件是 `prototype/public/RY.shortcut`，两者都不含连接码。模板随 VPS3 原型一起部署。私有连接码和收件记录保存在实例自己的数据目录。首次安装、微信分享菜单和 iOS 系统权限需在真机确认。

## Go 主站的手动连接

1. 用 Safari 打开收件箱，展开「连接 iPhone 快捷指令」。生成收件密钥，复制整个 Authorization 值。更换密钥后需要更新已安装的快捷指令。
2. 在「快捷指令」新建「交给 Bob」，开启「在共享表单中显示」，接收文件、图片和文本。无输入时获取剪贴板。
3. 添加「获取 URL 内容」，地址从收件箱复制，方法 POST，头部 Authorization 填上一步的值，请求体选表单。文件用名为 file 的文件字段。复制的文字用名为 text 的文本字段。可用「如果」按快捷指令输入类型选择两种请求。照片可先转换为 JPEG。最后从响应字典读取 message 并显示通知，view_url 可供后续打开。
4. 复制为「交给 Bob（带口令）」，在发送前加「请求输入」，将键入或听写的内容作为 instruction 文本字段。另一个副本可在开头加「截屏」，在 iPhone「辅助功能 → 触控 → 轻点背面」中绑定。使用微信当前页面实际提供的共享菜单，也可以复制消息或截屏。
5. 已订阅 Bob 主屏幕推送的设备沿用现有订阅。也可在收件箱填写 Bark 官方服务的设备 Key。首次投递后，可直接在收件箱查看状态。设备通知权限、安装快捷指令和锁屏送达须在本机验证。[Apple 快捷指令使用手册](https://support.apple.com/zh-cn/guide/shortcuts/welcome/ios)

## Go 主站的手机验收

- 发送「A品牌 2026年12月，单笔满10000元享5倍积分」。查看待确认卡，核对原话，选择含基础或额外加赠。可记住品牌口径。下载 Excel，检查 v1。
- 再发「A品牌 2026年12月活动，单笔门槛改为8000元」。核对 v2 中 10000 → 8000、同一行的积分口径及两条来源，分别下载两版 Excel。来源缺少品牌时，在详情中补充后确认。
- 分享海报截图，口令填「只记待办，周五前核对海报细节」。在收件详情及文员中核对待办与日期。仅给出日期的截止时间按 Bob 所设城市当地上午九点处理。
- 在手机关闭办公电脑后在本站重复投递一次相同原件与口令，确认返回同一编号。核对共享菜单、真实微信版本、Bark 或 PWA 锁屏点开效果。

## Go 主站的运行与恢复

Go 网关在私有 data/life/intake 下保存 SQLite 原件、活动事实和修订。Python 3 标准库负责事务；Excel 使用 openpyxl，PDF 使用 Poppler 的 pdfinfo、pdftotext 和 pdftoppm。GCP Ubuntu 对应软件包为 python3-openpyxl 和 poppler-utils。worker 重启后继续读取未完任务。已失败的输入可在详情中修正口令并重试。下载时按修订快照生成独立的积分台账，项目自有 Excel 模板需另行提供。

单份材料上限 12 MiB。支持文本、PNG/JPEG、PDF、CSV、XLSX 及包含这些材料的 ZIP。压缩包内最多 24 个支持的文件，展开总量上限 24 MiB。图片及扫描页合计最多 6 张，PDF 最多 12 页；超限的任务保留原件并提示拆分。指令、截图文字与附件内容会交给当前配置的模型。遇到模型不支持图片或余额不足，可切换模型再重试。Bark 仅接收通用收件通知和详情链接。

每台实例从本机数据目录读取独立的会话、收件密钥、推送订阅与模型设置。快捷指令向所属站点的 /api/ingest 投递，收件回执及通知中的链接也指向本站。
