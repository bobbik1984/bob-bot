# BobBot — Product Features & Acceptance Criteria（功能清单与验收标准）

> **状态**：2026-11-08 初始规划。本文定义 `bob-bot` 面向纯消费者的核心功能模块与可观测验收标准（当前处于立项阶段，具体已上线状态以 [CURRENT_STAGE.md](CURRENT_STAGE.md) 为准）。

---

## F1. 极简开箱与 BYOK 模型配置（Zero-Friction Onboarding）

- **F1.1 首次启动三步向导**：
  - 未初始化实例访问网页时强制跳转向导页：设置管理员密码 $\rightarrow$ 选择模型预设（DeepSeek / Gemini / OpenAI / Anthropic / OpenRouter）并填入 API Key $\rightarrow$ 连通性实测通过后进入主界面。
  - **验收标准**：填入有效 Key 后点击验证，2 秒内返回真实模型握手成功；API Key 写入 Linux `0600` `FileVaultSecretStore`，刷新页面或调接口绝不回传明文。
- **F1.2 快慢模型自动配对（Clerk & Maker）**：
  - 用户只需填 1 个 API Key，系统自动将该服务商下的轻量模型绑定为 Clerk（秒回/路由/记忆提取），旗舰模型绑定为 Maker（多步网页操控与深度推理），同时支持高级用户手动微调。

---

## F2. 云端浏览器与手机网页“虚拟窗口”人机接力（Cloud Browser & Virtual Window）

- **F2.1 无感后台网页自动执行**：
  - 用户用自然语言派发网页任务（如查价、抓内容、填表），主对话气泡下方实时展示当前步骤（正在打开网址、正在提取列表）与关键节点缩略图。
- **F2.2 聊天流内嵌“虚拟浏览器小窗”接管（Interactive Takeover）**：
  - 当遇到未登录、滑块验证码、二维码或 2FA 验证时，Worker 自动暂停并在聊天流弹出待接管卡片。二维码登录需要用第二台设备打开虚拟窗口。
  - 用户在手机或电脑浏览器点击「打开虚拟窗口」，画面通过 WebSocket 实时渲染云端 Chromium 当前标签页（支持触屏点击、滑动滑块、页面滚动、以及通过原生浮动输入框唤起手机输入法填入账号密码）。
  - **验收标准**：在 390px 手机浏览器视口下打开虚拟窗口，能成功完成一次真实网站的账号密码输入或滑块拖动，点击「交还给 Bob」后画面推流立即停止，Agent 在同一会话继续完成剩余步骤。
- **F2.3 网站持久化登录态中心（Site Session Vault）**：
  - 在「记忆与授权」面板列出曾登录过的网站域名、最后活跃时间与 Cookie 状态，支持一键打开某个网站的虚拟窗口预登录，或一键清除单个网站的登录态。

## F3. 分级安全审批门禁（Action Gates）

- **F3.1 读写分级拦截**：
  - 只读操作（打开网页、搜索、翻页、读取文本）自动执行。
  - 高危/外部副作用操作（点击付款/下单按钮、发布公开帖子、发送消息、删除数据）触发硬拦截，附带当前页面高亮截图推送至聊天流。
  - **验收标准**：未经用户在气泡内点击 `允许本次 (Allow Once)`，后台 Worker 绝不触发高危点击；超过 10 分钟未批自动转为安全挂起。

---

## F4. 示教转日常任务与消费级记忆（Routines & Memory Pills）

- **F4.1 一键存为日常任务（Walkthrough to Routine）**：
  - 任何成功跑完的网页/搜索任务卡片底部提供「存为日常任务」按钮，自动提炼执行步骤剧本，用户仅需选择执行频率（每天固定时间 / 每周 / 每隔 N 小时）。
  - **验收标准**：保存后的 Routine 到点自动唤醒云端浏览器静默执行，并将汇总结果作为新消息推入主对话；若遇到 Cookie 过期，自动暂停并推送虚拟窗口接管卡片。
- **F4.2 无感记忆胶囊（Memory Pills）**：
  - 自动从日常对话中提炼用户的长期偏好、常用信息和关注目标，以可视化标签卡展示在「记忆与授权」页，支持手动新增、编辑或一键删除。

---

## F5. 月度花费上限（Spending Limit）

- **F5.1 默认每月 $10**：只统计模型 API 费用，用户可在设置中调整并查看本月已用金额。
  - **验收标准**：用量达到 80% 时提醒；达到 100% 后不再发起新的模型调用，运行中的任务在当前步骤结束后挂起；提高上限后可继续。

---

## F6. 可选渠道与连接应用（Optional）

- **F6.1 消息渠道**：可选接入 Telegram、Lark、Discord、微信 Bot，用于发起任务、接收结果与提醒，默认关闭。
  - **验收标准**：未绑定的账号发送消息不触发任何任务；需要登录或接管时收到跳转网页虚拟窗口的链接，聊天中不收发密码。
- **F6.2 连接应用（MCP）**：可选接入现有 MCP 工具，写入类操作默认需要审批。
