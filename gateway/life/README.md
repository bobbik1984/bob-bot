# Bob · 随身助理

这个候选模块把 Bob 的手机首页连接到持续保存的愿望、收藏和个人行程。用户可交一段文字或一张图片；支持系统 Web Share Target 的设备安装到主屏幕后，可从分享菜单直接交给 Bob。使用原网关的登录会话，聊天和模型设置从首页右上角进入。

## 试一次顺路提醒

1. 用“替我留意”存下“去看展”，在“地点和时间”填“西岸美术馆”。可以同时附海报，如需提取信息，点“帮我提取”，核对后保存。
2. 再用“我的行程”存下“和朋友吃饭”，地点填“上海西岸”，选明天下午。首页会把“去看展”带回来，并显示触发它的实际行程。
3. 提醒上可以点「拟个日程」，核对名称、地点和时间后导出 30 分钟的 .ics 草稿，在自己的日历里确认。把吃饭行程标成“这次算了”，关联提醒会撤下。单独存一个 24 小时内截止的愿望，即使没有行程也会回来。用“只收藏”保存的材料只进入收藏记录。
4. 手机安装后允许“开启手机提醒”。服务端每 30 秒复核，页面关闭后仍会向受支持的 Web Push 服务提交提醒。通知不含私人事项正文。浏览器或系统可能延迟投递。

地点按原名或核对后的城市和街区匹配。老记录也可用场馆名与区域名匹配，例如“西岸美术馆”和“上海西岸”。城市冲突、两个仅前缀相似的场馆，或多个城市均有候选行程时，跳过区域提醒。系统检查未来 72 小时内的个人行程。行程可以手动添加，也可从手机或电脑选择 .ics 文件。页面在本机解析，只有你勾选并确认的单次行程会送到 Bob。再次导入同一 UID 会更新原行程，已结束的行程保持关闭。支持 UTC、IANA 时区及设备本地时间。重复、全天和时区无法判定的活动会显示在跳过计数中。首页「今天的安排」按设备本地日期列出行程和待办截止时间。这个摘要直接使用现有记录，无模型调用。系统日历后台同步、实时定位和地理距离计算属于后续范围。点击「帮我提取」才会发送笔记和所选截图到聊天设置当前选中的模型。支持 Gemini 原生接口和 OpenAI 兼容接口。请确认模型支持图片。建议中的城市、街区、日期可核对和修改，也可以手填。截图入口沿用 UTC 月度预算，发起前暂记 $0.01。已知旧费率或供应商返回美元账单时结算；缺少费率时保留估值，准确费用以供应商账单为准。

## GCP 源码发布

现在的 GCP 迭代方式是上传完整网关源码，在目标机用 Go 编译所有文件，再重启现有服务。首次试测可解压完整源码包，运行其中的 `Deploy-to-GCP.cmd` 或 `scripts/deploy-gcp.ps1`。首页使用 `gateway/life/web/home.html`，Go 版经典界面使用 `gateway/public/index.html`。使用条件、会话迁移及验证见[源码发布说明](../../scripts/gcp-source-guide.md)。

## 本地编译后发布二进制

主分支包含完整 Go 网关。进入 `gateway/` 运行 `go test ./...` 和 `go build .` 即可编译聊天和 Life。独立预览须设置自己的 `BOBBOT_PIN`，可设置 `BOBBOT_LISTEN_HOST=127.0.0.1` 仅在本机监听。

备选二进制发布器从同一个 Git 提交读取全部源码和资源。在原仓库执行以下命令，目标值来自节点台账和服务地图。

```powershell
python scripts/deploy-life.py --ref HEAD --host $sshAlias --url $publicOrigin --port $gatewayPort
```

参数 `--build-only` 用于只运行测试和交叉编译。发布器要求 GCP 目标原有 Go 服务、正确的 SSH 主机密钥与免交互重启权限。它保留旧二进制，核对新文件 SHA-256，并在远端执行本机及公网版本、首页和未登录访问检查。切换后验收失败会恢复旧二进制。候选版本端点为 `/api/life/version`；原网关版本端点继续报告网关基线。

## 使用完整发布包

Windows 解压后双击 `Try-on-Windows.cmd`。输入你自己选的六位以上数字 PIN，浏览器会打开本机网关。试用数据写入当前用户的 BobLifePreview 文件夹。关闭命令窗口即可结束服务。两次运行间可重新选择登录 PIN。

双击 `Deploy-to-GCP.cmd` 会用本机 Python 3 和已配置的 OpenSSH 别名向目标发布。无需本地 Git 或 Go。会检查原服务身份、凭据配置、架构、SHA-256、登录隔离与公网版本。原服务账号需要有免交互重启该服务的权限。原二进制保留在服务目录，新版启动或站点检查失败会尝试恢复。若 SSH 连接中断，以实际版本端点与服务目录中的备份为准。发布包只含程序、脚本、发布参数与说明。未选日历内容不上传，.ics 文件导入不会持续读取系统日历。

如需从源码构建相同格式，把发布命令加上 `--bundle bob-life.zip`。可在解包后运行 `python life_release.py verify` 校验两个二进制。
