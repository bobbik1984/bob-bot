# Bob · 随身助理

这个候选模块把 Bob 的手机首页连接到持续保存的愿望、收藏和个人行程。用户可交一段文字或一张图片；支持系统 Web Share Target 的设备安装到主屏幕后，可从分享菜单直接交给 Bob。使用原网关的登录会话，聊天和模型设置从首页右上角进入。

## 试一次顺路提醒

1. 用“替我留意”存下“去看展”，在“地点和时间”填“西岸美术馆”。可以同时附海报，如需提取信息，点“帮我提取”，核对后保存。
2. 再用“我的行程”存下“和朋友吃饭”，地点填“上海西岸”，选明天下午。首页会把“去看展”带回来，并显示触发它的实际行程。
3. 提醒上可以点「拟个日程」，核对名称、地点和时间后导出 30 分钟的 .ics 草稿，在自己的日历里确认。把吃饭行程标成“这次算了”，关联提醒会撤下。单独存一个 24 小时内截止的愿望，即使没有行程也会回来。用“只收藏”保存的材料只进入收藏记录。
4. 手机安装后允许“开启手机提醒”。服务端每 30 秒复核，页面关闭后仍会向受支持的 Web Push 服务提交提醒。默认锁屏仅显示通用文案，可在本机单独开启「锁屏显示提醒正文」。浏览器或系统可能延迟投递。

地点按原名或核对后的城市和街区匹配。老记录也可用场馆名与区域名匹配，例如“西岸美术馆”和“上海西岸”。城市冲突、两个仅前缀相似的场馆，或多个城市均有候选行程时，跳过区域提醒。系统检查未来 72 小时内的个人行程。行程可以手动添加，也可从手机或电脑选择 .ics 文件。页面在本机解析，只有你勾选并确认的单次行程会送到 Bob。再次导入同一 UID 会更新原行程，已结束的行程保持关闭。支持 UTC、IANA 时区及设备本地时间。重复、全天和时区无法判定的活动会显示在跳过计数中。首页「今天的安排」按设备本地日期列出行程和待办截止时间。这个摘要直接使用现有记录，无模型调用。系统日历后台同步、实时定位和地理距离计算属于后续范围。点击「帮我提取」才会发送笔记和所选截图到聊天设置当前选中的模型。支持 Gemini 原生接口和 OpenAI 兼容接口。请确认模型支持图片。建议中的城市、街区、日期可核对和修改，也可以手填。截图入口沿用 UTC 月度预算，发起前暂记 $0.01。已知旧费率或供应商返回美元账单时结算；缺少费率时保留估值，准确费用以供应商账单为准。


## 运行

在 gateway 目录设置自己的 BOBBOT_PIN，执行 go test ./... 和 go run . 。
