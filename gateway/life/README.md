# Bob · 随身助理

这个候选模块把 Bob 的手机首页连接到持续保存的愿望、收藏和个人行程。用户可交一段文字或一张图片；支持系统 Web Share Target 的设备安装到主屏幕后，可从分享菜单直接交给 Bob。使用原网关的登录会话，聊天和模型设置从首页右上角进入。

## 试一次顺路提醒

1. 用“替我留意”存下“去看展”，在“地点和时间”填“西岸”。可以同时附海报，如需提取信息，点“帮我提取”，核对后保存。
2. 再用“我的行程”存下“和朋友吃饭”，地点也填“西岸”，选明天下午。首页会把“去看展”带回来，并显示触发它的实际行程。
3. 把吃饭行程标成“这次算了”，关联提醒会撤下。单独存一个 24 小时内截止的愿望，即使没有行程也会回来。用“只收藏”保存的材料只进入收藏记录。
4. 手机安装后允许“开启手机提醒”。服务端每 30 秒复核，页面关闭后仍会向受支持的 Web Push 服务提交提醒。通知不含私人事项正文。浏览器或系统可能延迟投递。

本版地点按规范化名称匹配，检查未来 72 小时内的个人行程。行程由用户在 Bob 内添加；系统日历接入、实时定位和地理距离计算属于后续范围。截图提取按需使用官方 OpenAI 账号的视觉模型；应用端记账按 UTC 自然月归集该入口的用量，计入可用预算判断。凭证来自运行网关已有 OpenAI 配置，截图发送前由用户点击确认提取，人工填写也能完成全流程。

## 构建与发布

GitHub 基线不包含 GCP 运行中的 Go 网关。必须在有 `gateway/main.go`、`features.go`、`go.mod` 和 `gateway/public/` 的原工作副本执行。发布器将网关当前工作文件复制到临时位置，将候选模块挂到已有路由，执行模块和完整网关测试，交叉编译，再用已配置的 SSH 别名发布。原仓库及现有数据文件不被构建步骤改写。

在原仓库的 PowerShell 中执行：

```powershell
git fetch origin refs/heads/prototype/mobile-life
if ($LASTEXITCODE -eq 0) { git show FETCH_HEAD:scripts/deploy-life.py | python - --repo . --ref FETCH_HEAD }
```

参数 `--build-only` 用于只运行测试和交叉编译。发布器要求 GCP 目标原有 Go 服务、正确的 SSH 主机密钥与免交互重启权限。它保留旧二进制，核对新文件 SHA-256，并在远端执行本机及公网版本、首页和未登录访问检查。切换后验收失败会恢复旧二进制。候选版本端点为 `/api/life/version`；原网关版本端点继续报告网关基线。
